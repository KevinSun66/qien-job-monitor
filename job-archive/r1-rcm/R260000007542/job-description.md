## Official role summary

R37 is R1 RCM's AI innovation lab. The position owns production runtime work for Phare's ML stack, including model deployment, serving and scaling across inference endpoints and batch/streaming workflows. Responsibilities include progressive delivery, automated rollout and rollback, SLO management, observability for latency, availability, drift and regression, and platform hardening with Terraform, Kubernetes and CI/CD.

## Required background

The official description does not state a numeric minimum number of professional years. It does require prior production-level capability:

- operating ML systems at scale;
- deploying and operating GPU-backed models in production;
- Docker/Kubernetes, infrastructure as code and CI/CD;

- end-to-end reliability practices and incident response.
