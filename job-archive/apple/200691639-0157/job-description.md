## Official role summary

Apple Ads' Data Insights organization is hiring an Applied AI Engineer to build AI-powered analytics and decision-support platforms. The role combines software engineering, machine learning, statistics and agentic AI. The engineer will connect large language models with internal data infrastructure, analytical tools and business knowledge.

## Responsibilities

- Design and build scalable AI agent systems connecting LLMs with data infrastructure, APIs and analytical tools.
- Advance agent orchestration, including tool calling, memory, MCPs, context retrieval and routing.
- Build reusable platform components for AI-powered analytical workflows.
- Build evaluation frameworks and monitoring for agent accuracy, reliability and performance.
- Improve retrieval quality, reasoning, accuracy and traceability through ML and analytical methods.
- Develop AI-native systems from concept through production.
- Translate analytical workflows and domain knowledge into reusable AI capabilities with engineers, data scientists and business stakeholders.

## Minimum qualifications

- Bachelor's degree in Computer Science, Engineering, Machine Learning, Data Science or a related field, or equivalent practical experience.
- Experience designing, building and deploying production software systems; strong Python and software-engineering fundamentals.
- Hands-on experience building and deploying LLM applications using agentic workflows, tool calling, RAG or related techniques.
- Experience with large-scale data platforms or distributed data systems.
- Foundation in AI, machine learning, statistics and software engineering.
- Problem solving, communication and cross-functional collaboration.

The official minimum qualifications do not state a numeric minimum of one or more years.

## Preferred qualifications

- Production AI agent platforms with multi-step orchestration, tool execution, memory and context management.
- LLM evaluation frameworks, regression benchmarks and observability.
- Advanced retrieval, embeddings, model fine-tuning or inference optimization.
- Natural-language-to-SQL, analytical agents or AI decision-support systems.
- Advanced degree in a related technical field.
