## Official role summary

Apple Ads' Data Insights organization is hiring a Senior Applied AI Engineer to build AI-powered analytics and decision-support platforms. The role combines software engineering, machine learning, statistics and agentic AI, connecting large language models with internal data infrastructure, analytical tools and business knowledge.

## Responsibilities

- Design and build scalable AI agent systems connecting LLMs with data infrastructure, APIs and analytical tools.
- Advance agent orchestration, including tool calling, memory, MCPs, context retrieval and intelligent routing.
- Build reusable platform components for AI-powered analytical workflows.
- Build evaluation frameworks and monitoring for accuracy, reliability, traceability and performance.
- Develop AI-native systems from concept through production.
- Partner with engineers, data scientists and business stakeholders.

## Minimum qualifications

- **7+ years of experience.**
- Bachelor's degree in Computer Science, Engineering, Machine Learning, Data Science or a related field, or equivalent practical experience.
- Production software-system design and deployment; strong Python and software-engineering fundamentals.
- Hands-on production LLM applications using agentic workflows, tool calling, RAG or related techniques.
- Experience with large-scale data platforms or distributed data systems.
- Foundation in AI, machine learning, statistics and software engineering.

## Preferred qualifications

- Production AI agent platforms with multi-step orchestration, tool execution, memory and context management.
- LLM evaluation frameworks, regression benchmarks and observability.
- Advanced retrieval, embeddings, model fine-tuning or inference optimization.
- Natural-language-to-SQL, analytical agents or AI decision-support systems.
- Advanced degree in a related technical field.

## Compensation

Official posting range: $150,400–$277,600 base, with possible equity, discretionary bonus or commission, benefits and relocation depending on eligibility.
